# Saraya Medical System — حزمة تحسين الجاهزية الأولى

التاريخ: 2026-10-27. النطاق: إصلاحات محلية واختبارات في المستودع؛ لم يحدث نشر
إلى بيئة إنتاج أو تعديل لبيانات المرضى أو تدوير مفاتيح التشفير.

## تصحيح نتائج المراجعة السابقة

- بناء Vite وPWA الحالي ناجح. خطأ DICOM المذكور سابقاً كان من سجل بناء قديم؛
  لا يصح اعتباره عطلاً مثبتاً في النسخة الحالية. لم نغيّر إعداد DICOM.
- اكتمل فحص الخادم قبل التغييرات: 67 مجموعة، 587 اختباراً ناجحاً، و4 متخطاة.
  أرقام الفشل الواردة سابقاً نُقلت من سجل قديم ولا تمثل نتيجة النسخة الحالية.
- بيانات coverage الموجودة قديمة وغير مرتبطة بتشغيل كامل موثق في هذه الحزمة؛
  لا نعتمد نسبتها لتقييم التغطية الحالية.
- فحص تصريحات الحماية في Controllers ناجح، لكنه فحص نصي لا يثبت عزل البيانات
  أثناء التشغيل أو صحة كل سياسة ABAC.

## التغييرات

1. **سلامة الترحيلات — `c450385`:** إزالة معالجة الفشل التي قد تحذف سجل
   migrations أو تنفذ `db push --accept-data-loss`. أخطاء الترحيل الدائمة توقف
   التشغيل، مع إبقاء إعادة المحاولة للأخطاء المؤقتة. أضيف دليل استرداد واختبار
   يشغّل entrypoint الحقيقي بأوامر وهمية دون قاعدة بيانات.
2. **أسرار الإنتاج — `ac0184a`:** رفض JWT ومفتاح التشفير الفارغين، والقيم
   التجريبية المعروفة، والقيم الأقصر من 32 حرفاً. الاختبارات تتحقق أيضاً من عدم
   تسريب القيمة إلى سجل الخطأ. لم نغيّر المفتاح أو salt الموجودين؛ تغييرهما مع
   بيانات مشفرة يتطلب ترحيلاً مخططاً ومختبراً.
3. **بوابات الجودة — `0dc8499`:** إضافة فحص PR، بناء الخادم، تحقق Prisma،
   اختبارات الواجهة، واختبارات بدء الترحيلات. استبدال `lint || true` ببوابة
   تمنع زيادة أخطاء ESLint لكل ملف وقاعدة، مع إبقاء الأخطاء القديمة موثقة.
   فصل lint غير المعدّل عن أمر الإصلاح التلقائي. PR لا ينشر صور Docker.
4. **اختبارات E2E — `16b373b`:** تصحيح نماذج Prisma وتجهيز المستخدمين وissuer الخاص
   بتوكن الموظفين وشكل استجابة المرضى. إزالة تجاهل أخطاء اختبار المشتريات
   وإضافة اختبار رفض الكتابة لمستخدم القراءة. حماية reset من استهداف قاعدة
   غير مخصصة للاختبار، والتحقق من اسم القاعدة المتصلة، وتمرير الفشل للاختبار.
   إضافة فحص TypeScript الشامل واختبارات سلامة reset إلى CI.
5. **خفض الدين التقني:** خط الأساس انخفض من 5473 إلى 5354 خطأ ESLint،
   دون تعطيل القواعد. ما زالت 5354 أخطاء و630 تحذيراً تحتاج المعالجة؛ نجاح
   بوابة منع الزيادة لا يعني أن فحص lint الكامل أصبح نظيفاً.

sandbox على Windows. فشل EPERM داخل sandbox لا يُعد عطلاً في التطبيق.
تم فحص بنية YAML محلياً؛ تشغيل GitHub Actions نفسه يحتاج دفع التغييرات إلى GitHub.

## العمل المتبقي قبل قرار الإطلاق

- تشغيل E2E على PostgreSQL وRedis معزولين، ثم اختبار دورة المريض والمشتريات
  والفوترة والصيدلية والعزل بين المستأجرين. تصحيح الأنواع وحده ليس إثبات تشغيل.
- مقارنة قاعدة النشر الفعلية بملفات migrations، والتدرب على النسخ والاستعادة
  وتسجيل RTO/RPO. لم يتم توصيل الاختبارات بقاعدة الإنتاج.
- تدوير Telegram token الذي سبق كشفه لدى مزود الخدمة؛ تعديل الملف المحلي
  أو تجاهله في Git لا يلغيه. لا ينشر هذا التقرير أي قيمة سرية.
- مراجعة إدارة Vault، وحقوق الوصول، والقيم الافتراضية في Compose، وسياسة تحديث
  Watchtower، وتثبيت إصدارات الصور مع خطة رجوع قابلة للتنفيذ.
- معالجة الدين المتبقي، وقياس coverage جديد، وإثبات اختبارات الحمل والتزامن.
- إجراء قبول سريري وUAT وتحقق تكاملات خارجية، وتجهيز الهاتف لإصدار إنتاجي.

هذه الحزمة ترفع السلامة وقابلية التحقق، ولا تمثل شهادة اكتمال أو موافقة إطلاق.
